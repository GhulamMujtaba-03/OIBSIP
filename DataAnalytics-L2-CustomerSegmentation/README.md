# Customer Segmentation Analysis

## Objective

The objective of this project is to segment customers based on their purchasing behaviour using the K-Means Clustering algorithm. Customer segmentation helps businesses understand different customer groups and create targeted marketing strategies.

---

## Dataset

- Dataset: Online Retail Dataset
- Source: Kaggle (UCI Online Retail Dataset)

---

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook (Anaconda)

---

## Project Workflow

- Imported required libraries
- Loaded the dataset
- Performed initial data inspection
- Checked missing values
- Removed duplicate records
- Removed invalid transactions
- Converted InvoiceDate to datetime format
- Created TotalAmount column
- Calculated average purchase value
- Calculated purchase frequency
- Calculated customer lifetime value
- Performed RFM Analysis
- Standardized the data using StandardScaler
- Applied the Elbow Method
- Built customer segments using K-Means Clustering
- Visualized customer clusters
- Created cluster profiles
- Recommended marketing strategies for each customer segment

---

## Visualizations

- Elbow Method
- Recency vs Monetary Scatter Plot
- Frequency vs Monetary Scatter Plot
- Number of Customers per Cluster

---

## Results

Customers were divided into different groups based on their purchasing behaviour using RFM Analysis and K-Means Clustering. Each cluster represents a unique customer segment that can be targeted with different marketing strategies.

---

## Conclusion

Customer segmentation helps businesses identify valuable customers, improve customer retention, and create personalized marketing campaigns. The K-Means clustering algorithm successfully grouped customers based on their purchasing behaviour.
