# Oasis Infobyte Data Analytics Internship

## Overview

This repository contains all the projects completed during the **Oasis Infobyte Data Analytics Internship**. Each task demonstrates practical data analysis and machine learning skills using Python and its data science libraries.

The projects cover Exploratory Data Analysis (EDA), Customer Segmentation, House Price Prediction, Wine Quality Prediction, and Data Cleaning.

---

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook (Anaconda)

---

# Projects

## Task 1 – Exploratory Data Analysis (EDA) on Retail Sales Data

**Objective**

Analyze retail sales data to identify trends, customer behavior, and product performance using Exploratory Data Analysis (EDA).

**Topics Covered**

* Data Inspection
* Missing Value Check
* Duplicate Removal
* Date Feature Engineering
* Descriptive Statistics
* Monthly & Quarterly Sales Trends
* Customer Age Analysis
* Gender Distribution
* Revenue Analysis
* Product Category Analysis
* Correlation Heatmap

---

## Task 2 – Customer Segmentation Analysis

**Objective**

Segment customers based on purchasing behavior using the RFM (Recency, Frequency, Monetary) model and K-Means Clustering.

**Topics Covered**

* Data Cleaning
* RFM Feature Engineering
* Data Standardization
* Elbow Method
* K-Means Clustering
* Cluster Visualization
* Customer Segmentation
* Marketing Recommendations

---

## Task 3 – House Price Prediction

**Objective**

Build a Linear Regression model to predict house prices based on housing features.

**Topics Covered**

* Data Cleaning
* Feature Selection
* One-Hot Encoding
* Correlation Analysis
* Train/Test Split
* Linear Regression
* Model Evaluation (MSE, RMSE, R² Score)
* Actual vs Predicted Plot
* Residual Plot
* Coefficient Analysis

---

## Task 4 – Wine Quality Prediction

**Objective**

Train and compare multiple machine learning classification models to predict wine quality.

**Models Used**

* Random Forest Classifier
* Stochastic Gradient Descent (SGD) Classifier
* Support Vector Classifier (SVC)

**Topics Covered**

* Data Cleaning
* Exploratory Data Analysis
* Class Distribution
* Correlation Heatmap
* Feature Engineering
* Train/Test Split
* Model Evaluation
* Confusion Matrix
* Feature Importance
* Model Comparison

---

## Task 5 – Data Cleaning

**Objective**

Clean a messy dataset and prepare it for data analysis.

**Topics Covered**

* Data Quality Report
* Missing Value Handling
* Duplicate Removal
* Data Standardization
* Outlier Detection (IQR Method)
* Data Type Correction
* Before vs After Comparison
* Export Clean Dataset
